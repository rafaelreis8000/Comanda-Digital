# Visão de Produto - Comanda Digital

## 1. Visão Geral

O comanda digital será um sistema para auxiliar restaurantes de pequeno porte no gerenciamento de clientes, cardápio, mesas, comandas e pedidos.

A primeira versão será voltada para restaurantes com atendimento presencial sem delivery.

O sistema será inicialmente desenvolvido como uma aplicação web, podendo futuramente receber uma versão desktop e mobile.

## 2. Problemas

O controle manual de pedidos e comandas pode gerar:

- Erros nos pedidos;
- Perda de informação;
- Dificuldade no controle das mesas;
- Demora no atendimento;
- Falta de organização nos pedidos;

O sistema busca centralizar essas informações, tornando o atendimento mais organizado, confortável e funcional.

## 3. Objetivo

Criar um sistema que permita:

- Cadastrar clientes;
- Cadastrar produtos e categorias;
- Controlar mesas;
- Abrir e fechar comandas;
- Registrar pedidos;
- Acompanhar pedidos;
- Calcular o total da comanda;

## 4. Escopo Inicial - MVP

### Clientes

- Cadastrar;
- Consultar;
- Alterar;
- Remover;

### Cardápio

- Cadastrar Categorias (bebidas, entradas, pratos principais, sobremesas...);
- Cadastrar produtos;
- Alterar produtos;
- Remover produtos;
- Controlar disponibilidade;

### Mesas

- Cadastrar mesas;
- Visualizar mesas;
- Controlar disponibilidade;

### Comandas

- Abrir comanda;
- Associar mesa e cliente;
- Adicionar pedidos;
- Consultar pedidos;
- Calcular total;
- Fechar comanda;

### Pedidos

- Adicionar produto;
- Alterar quantidade;
- Adicionar observações;
- Alterar status;

## 5. Funcionalidades extras

Algumas funcionalidades não são fundamentais para o sistema, sendo tratadas como extra. São elas:

- Delivery;
- Pagamentos online;
- Aplicativo mobile;
- Geração de relatórios;
- Controle de estoque;
- Integrações externas;
