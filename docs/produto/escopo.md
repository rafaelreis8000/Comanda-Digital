# Escopo do Projeto - Comanda Digital

## 1. Objetivo

Desenvolver um sistema de comandas para restaurantes de pequeno porte, de início somente para atendimento presencial, permitindo a gestão de clientes, cardápio, mesas, pedidos e comandas

## 2. Funcionalidades

- Cadastro de clientes;
- Cadastro de categorias e produtos;
- Controle de mesas;
- Abertura e encerramento de comandas;
- Inclusão, alteração e remoção de itens;
- Controle do status dos pedidos;
- Cálculo do valor total da comanda;
- Consulta do histórico de pedidos;

## 3. Fora do Escopo Inicial

- Delivery;
- App mobile nativo;
- App desktop nativo;
- Controle financeiro completo;
- Emissão fiscal;
- Controle avançado de estoque;
Integrações com marketplaces;
- Sistemas externos de pagamento;
- Relatórios avançados;
