# Requisitos Não Funcionais

## 1. Desempenho

- **RNF01:** O sistema deve apresentar respostas rápidas nas operações comuns.
- **RNF02:** O sistema deve suportar vários usuários utilizando a aplicação simultaneamente.

## 2. Usabilidade

- **RNF03:** A interface deve ser simples e intuitiva.
- **RNF04:** O sistema deve ser responsivo e funcionar em computadores, tablets e smartphones.
- **RNF05:** O sistema deve apresentar mensagens claras para erros e operações realizadas.

## 3. Segurança

- **RNF06:** O acesso às funções administrativas deve exigir autenticação.
- **RNF07:** O sistema deve controlar o acesso de acordo com as permissões do usuário.
- **RNF08:** Dados sensíveis devem ser armazenados de forma segura.
- **RNF09:** Senhas não devem ser armazenadas em texto puro.

## 4. Confiabilidade

- **RNF10:** O sistema deve validar os dados antes de armazená-los.
- **RNF11:** O sistema deve evitar perda ou inconsistência dos dados.
- **RNF12:** O sistema deve possuir backup dos dados importantes.

## 5. Compatibilidade

- **RNF13:** A aplicação web deve funcionar nos principais navegadores modernos.
- **RNF14:** O sistema deve funcionar em diferentes sistemas operacionais.
- **RNF15:** A arquitetura deve permitir futuramente a criação de aplicativos para Android e iOS.

## 6. Manutenção

- **RNF16:** O código deve ser organizado e seguir princípios de orientação a objetos.
- **RNF17:** O sistema deve possuir separação de responsabilidades entre seus componentes.
- **RNF18:** O código e a documentação devem utilizar controle de versão.

## 7. Escalabilidade

- **RNF19:** O sistema deve permitir a inclusão de novas funcionalidades sem grandes alterações na estrutura existente.
- **RNF20:** A arquitetura deve permitir futuramente a inclusão de funcionalidades de delivery.

## 8. Privacidade

- **RNF21:** Os dados pessoais dos clientes devem ser protegidos.
- **RNF22:** O tratamento dos dados deve respeitar a LGPD.

## 9. Testes

- **RNF23:** As principais regras de negócio devem permitir a realização de testes automatizados.
