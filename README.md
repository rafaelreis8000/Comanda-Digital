# Comanda Digital

## Objetivo

Desenvolver um sistema de gerenciamento de comandas num restaurante permitindo o controle de

- Clientes
- Mesas
- Cardápio
- Produtos
- Pedidos
- Itens dos pedidos
- Fechamento da comanda
- Pagamentos
- Usuários e funcionários
- Delivery (futuramente)
